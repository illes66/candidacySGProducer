# Say Games Producer Candidacy - Playable

## 📁 Project Structure

```
candidacySGProducer/
├── Unity-3D-PC/          # Unity 3D playable for PC (coming soon)
└── Web-2D-JS/            # Web playable in JavaScript + HTML/CSS
    ├── index.html        # Main structure
    ├── css/
    │   └── style.css     # Complete styling (dark theme, neon colors)
    ├── js/
    │   ├── config.js     # Configuration & requirements data
    │   ├── main.js       # Entry point
    │   ├── gameManager.js        # Game flow controller
    │   ├── uiManager.js          # UI elements management
    │   ├── requirementHandler.js # Interaction handler
    │   └── animationController.js # Anime.js animations
    └── README.md
```

## 🎮 How It Works

1. **Click the interactive box** (📦) in the center
2. **Requirement highlights** on the right screen
3. **Your experience description** appears in the UI
4. **Checkmark animates** on your CV (left screen)
5. **Repeat 9 times** for all requirements
6. **Final congratulations message** displays your contact info

## 🛠️ Technologies

- **HTML5** - Semantic structure
- **CSS3** - Dark neon theme, responsive design
- **Vanilla JavaScript (ES6+)** - No frameworks
- **Anime.js** - Smooth animations and VFX
- **GitHub Pages** - Hosting

## 📝 Configuration

Edit `js/config.js` to:
- Add your requirements and descriptions
- Update personal information (name, email, LinkedIn)
- Customize timing and colors
- Enable debug mode

## 🚀 Getting Started

1. Clone the repository
2. Open `Web-2D-JS/index.html` in a browser
3. Update `config.js` with your data
4. Deploy to GitHub Pages
